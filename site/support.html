Support

Setup

  1. Install and open Go Rot for Mac, then choose Set up Go Rot.
  2. Select Codex, Claude, or both. Go Rot changes only its own local hook entries for the agents you choose.
  3. When Chrome opens, choose Add to Chrome and pin Go Rot to the toolbar. Keep the Mac app open until it says Ready to rot.
  4. Open the panel, choose a feed, and run the feed check.
  5. Restart Codex or Claude. Codex CLI users must also enter /hooks once and trust the Go Rot hooks.

Companion unavailable

Reopen the Go Rot Mac app. It checks the connection automatically. To add, remove, or switch agents, choose Change agents… in the app or Go Rot → Change Agents… from the app menu. If Chrome still needs attention, reload the extension from chrome://extensions.

Agent stopped, feed still open

Codex Desktop's UI Stop action may not emit a usable lifecycle event. Open the extension panel and choose Clear stuck. This resets Go Rot without interrupting the agent.

Remove Go Rot

Open the Go Rot menu and choose Remove Go Rot Setup. Then remove the extension in chrome://extensions.

Still stuck?

Open a support issue on GitHub. Include your macOS version, Chrome version, agent surface, and the setup screen where you became stuck. Do not include prompts, answers, source code, or private browsing information.
