Support

Setup

  1. Install and open Go Rot for Mac, then choose Install or repair setup.
  2. Add Go Rot from the Chrome Web Store and pin it to the toolbar.
  3. Open the panel, choose a feed, and run the feed check.
  4. Restart Codex or Claude. Codex CLI users must also enter /hooks once and trust the Go Rot hooks.

Companion unavailable

Open the Go Rot Mac app and choose Install or repair setup, then reload the extension from chrome://extensions. Use Check readiness in the Mac app for a detailed health check.

Agent stopped, feed still open

Codex Desktop's UI Stop action may not emit a usable lifecycle event. Open the extension panel and choose Clear stuck. This resets Go Rot without interrupting the agent.

Remove Go Rot

Open the Go Rot Mac app and choose Remove Go Rot setup. Then remove the extension in chrome://extensions and move the Go Rot app to Trash.

Still stuck?

Open a support issue on GitHub. Include your macOS version, Chrome version, agent surface, and the output from Check readiness. Do not include prompts, answers, source code, or private browsing information.
